# BIEN BOARD — Demo

نسخه Demo / Prototype پلتفرم فروشگاهی مبتنی بر بازی.

## اجرا
فایل‌ها را در یک Repository قرار دهید و GitHub Pages را برای Branch اصلی فعال کنید.

برای تست محلی می‌توانید از یک Static Server استفاده کنید، مثلاً:

```bash
python -m http.server 8000
```

سپس:
`http://localhost:8000`

## امکانات Demo
- فروشگاه فارسی و RTL
- Mobile First / Responsive
- PWA و نصب روی Home Screen
- مسابقات فعال و Countdown
- ۳ فرصت رایگان برای هر محصول
- بازی Puzzle
- بازی Runner
- امتیاز و Leaderboard نمایشی
- Winner / Discount Code flow
- سبد خرید و Checkout شبیه‌سازی‌شده
- پنل مدیریت
- افزودن، ویرایش و حذف محصول
- دسته‌بندی قابل تغییر از طریق فرم محصول
- ذخیره داده‌ها در LocalStorage
- Reset Demo

## نکته
این نسخه برای ارائه و اعتبارسنجی ایده ساخته شده و Backend، احراز هویت واقعی، SMS، Email، درگاه پرداخت و ضدتقلب واقعی ندارد.
