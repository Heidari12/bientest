# BIEN BOARD Demo

نسخه دمو و قابل ویرایش BIEN BOARD برای GitHub Pages.

## امکانات اصلی این نسخه
- پنل مدیریت جداگانه برای دسته‌بندی و محصول
- افزودن/ویرایش/حذف دسته‌بندی‌ها
- افزودن/ویرایش/حذف هر تعداد محصول
- تغییر نام، برند، قیمت، موجودی، توضیحات، مشخصات، دسته‌بندی، بسته‌بندی، تخفیف و تصویر
- آپلود تصویر JPEG/JPG/PNG از داخل پنل مدیریت
- تعیین اینکه محصول مسابقه داشته باشد یا فروش عادی باشد
- تعیین تعداد فرصت رایگان هر محصول
- سه بازی سالم و واکنش‌گرا: پازل سرعتی، بپر بپر، شکار تخفیف
- پشتیبانی مناسب از لمس و موبایل
- ذخیره تغییرات دمو در localStorage مرورگر

## GitHub Pages
محتویات این پوشه را مستقیماً در Root ریپازیتوری قرار بده؛ سپس Settings → Pages → Deploy from a branch → main → /(root).

## نکته
این نسخه برای ارائه و Prototype است. localStorage جایگزین دیتابیس واقعی نیست و برای نسخه عملیاتی باید احراز هویت، دیتابیس، ذخیره‌سازی تصاویر، محاسبه امتیاز سمت سرور و صدور کد تخفیف سمت سرور اضافه شود.
