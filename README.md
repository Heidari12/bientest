# BIEN BOARD Demo v14

- اصلاح جهت دکمه‌های چپ و راست بازی مار: دکمه چپ واقعاً حرکت چپ و دکمه راست واقعاً حرکت راست را انجام می‌دهد.
- آیکون PWA از لوگوی BIEN BOARD ساخته شده و برای Android/Chrome و iOS home-screen آماده شده است.
- برای دریافت آیکون جدید، نسخه جدید فایل‌ها را روی GitHub Pages جایگزین کنید و سپس از دکمه «بروزرسانی» داخل سایت استفاده کنید. اگر شورتکات قدیمی هنوز آیکون قبلی را نشان می‌دهد، ممکن است لازم باشد یک‌بار شورتکات قدیمی را حذف و دوباره Add to Home screen کنید؛ خود سایت و داده‌ها حذف نمی‌شوند.
