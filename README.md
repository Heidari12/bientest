# BIEN BOARD — Demo v9

نسخه نمایشی PWA فارسی و راست‌چین BIEN BOARD برای GitHub Pages.

## تغییرات این نسخه
- ذخیره و همگام‌سازی خودکار تنظیمات محصولات و دسته‌بندی‌ها بین دستگاه‌ها؛ بدون دانلود/آپلود فایل پشتیبان.
- اتصال ابری سبک برای دمو؛ در صورت قطع سرویس، نسخه محلی مرورگر همچنان کار می‌کند.
- پازل تصویری سخت‌تر: ۴×۴ (۱۵ تکه + خانه خالی).
- رفع مشکل پرش صفحه در بازی «بپر بپر» روی موبایل با قفل اسکرول و کنترل لمسی پایدارتر.
- تنظیم زمان باقی‌مانده هر مسابقه از پنل مدیریت بر حسب دقیقه.
- تنظیم امتیاز ثابت ۵ شرکت‌کننده نمایشی برای هر محصول.
- نمایش لحظه‌ای «نفر اول هستی» وقتی امتیاز کاربر از همه امتیازهای ثابت بیشتر شود.
- پس از پایان زمان مسابقه، اگر امتیاز کاربر بالاترین باشد، پنجره برنده شدن و کد تخفیف نمایش داده می‌شود.
- کدهای تخفیف برنده در بخش «جوایز من» با نام محصول، نوع بازی، امتیاز و تاریخ اعتبار ذخیره می‌شوند.
- پنل مدیریت همچنان از بخش عمومی سایت جداست.

## نکته مهم درباره ذخیره ابری دمو
برای اینکه شما هیچ حساب یا سایت دیگری را تنظیم نکنید، این نسخه از یک سرویس JSON ابری سبک برای Prototype استفاده می‌کند. داده‌های تنظیمات و محصولات از طریق یک namespace اختصاصی داخل خود برنامه خوانده/نوشته می‌شوند.

این راهکار برای **دمو و ارائه سرمایه‌گذاری** مناسب است، نه برای اطلاعات حساس، پرداخت واقعی یا نسخه Production. برای نسخه نهایی بهتر است همین ساختار به دیتابیس اختصاصی با احراز هویت و سطح دسترسی (مثلاً Supabase) منتقل شود.


### بروزرسانی از روی گوشی
در نسخه v7 یک دکمه «🔄 بروزرسانی» در بالای سایت اضافه شده است. با زدن آن، Service Worker و Cache قدیمی پاک می‌شوند، آخرین نسخه فایل‌های سایت دریافت می‌شود و صفحه دوباره باز می‌شود. اطلاعات محصولات و تنظیمات ابری/محلی پاک نمی‌شوند.

## BIEN BOARD v8
- Startup now waits for the shared cloud configuration before rendering the storefront, so products/competitions/opponent scores configured in Management are applied immediately on first load.
- Runner game blocks long-press, selection, drag, context menu, touch scrolling and browser gestures inside the game area.
- Management area has a demo password gate.
- Demo admin password: `BIEN-ADMIN-1404`
- Note: this is a client-side demo gate, not production-grade security. For production, use authenticated backend/RLS.
