# BIEN BOARD — Demo

نسخه نمایشی فارسی و موبایل‌محور BIEN BOARD.

## امکانات این نسخه
- لوگوی رسمی BIEN BOARD مطابق طراحی ارسالی
- فروشگاه، دسته‌بندی و مسابقات
- پنل مدیریت جداگانه برای دسته‌بندی‌ها و محصولات
- ویرایش نام، برند، قیمت، موجودی، توضیحات، مشخصات، تخفیف، نوع بازی، فرصت رایگان و تصویر محصول
- انتخاب بسته‌بندی از فهرست کشویی
- آپلود JPEG/JPG/PNG و فشرده‌سازی خودکار تصویر برای نگهداری بهتر در دمو
- سه بازی: پازل تصویری ۳×۳، بپر بپر و شکار تخفیف
- کنترل لمسی و طراحی مناسب موبایل
- ذخیره خودکار روی همان دستگاه
- دانلود و بازیابی نسخه پشتیبان JSON برای انتقال تنظیمات و محصولات بین دستگاه‌ها

## نکته مهم درباره ذخیره بین دستگاه‌ها
GitHub Pages فقط فایل‌های سایت را میزبانی می‌کند و دیتابیس مشترک بین گوشی و کامپیوتر نیست. بنابراین این نسخه برای دمو اطلاعات را در مرورگر ذخیره می‌کند. برای انتقال اطلاعات، در پنل مدیریت «دانلود نسخه پشتیبان» و در دستگاه مقصد «بازیابی» را استفاده کنید.

برای نسخه واقعی باید پنل مدیریت به دیتابیس/فضای ذخیره‌سازی ابری متصل شود.
